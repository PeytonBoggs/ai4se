Java Methods Dataset - Collection Report
==========================================

OVERVIEW
--------
This dataset contains 25,000 Java methods collected from 10 open-source repositories.
Training examples: 20,000
Evaluation examples: 5,000

------------

- https://github.com/spring-projects/spring-boot

- https://github.com/junit-team/junit5
- https://github.com/mockito/mockito
- https://github.com/apache/commons-lang
- https://github.com/google/guava

EXTRACTION PROCESS
------------------
1. Repository crawling using GitHub API
2. Java file identification (.java extension)
3. Method boundary detection using AST parsing
4. Metadata extraction (signatures, comments, tokens)
5. Quality filtering and validation

CLEANING & FILTERING
--------------------
Applied the following filters:
- Minimum method length: 3 lines
- Maximum method length: 100 lines
- Excluded empty methods or comment-only methods
- Excluded methods with parsing errors
- Excluded non-Java files
- Deduplicated identical method signatures

STATISTICS
----------
Total methods processed: 25,000

Average method length: 44 lines
Repositories crawled: 10

FILE FORMAT
-----------
The CSV files contain the following columns:
- dataset_split: 'train' or 'eval'
- example_id: Unique identifier with repo@commit:file#lines format
- repo_name, repo_url, commit_sha, license: Repository metadata
- file_path, language: File information
- method_name, qualified_name: Method identifiers
- start_line, end_line: Method boundaries in source file
- signature: Method signature
- original_code: Complete method source code
- doc_comment: Javadoc comment if present
- code_tokens: Tokenized method code
